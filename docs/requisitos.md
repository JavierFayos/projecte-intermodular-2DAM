# Requisits

1. Funcionals
    1.1 Registrar gossos
    1.2 Consultar gossos
    1.3 Buscar gossos
    1.4 Gestionar dades gossos
    1.5 Crear noves reserves
    1.6 Cancel·lar reserves
    1.6 Introduïr dades de les reserves
    1.7 Consultar dades de les reserves
    1.8 Consultar calendari

2. No funcionals
    2.1 Interficie clara (tauler de control o dashboard)
    2.2 Integritat dades obligatories (validació existencia)
    2.3 Persistència de les dades (guardat a la BD)

3. Regles de negoci
    3.1 Dates de reserva (Eixida anterior a la reserva, etc)
    3.2 Disponibilitat (reserves duplicades)
    3.3 Associació reserves (cada reserva registrada a un gos)
