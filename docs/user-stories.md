# User stories

El següent document parteix de la base d'un negoci menut en el que el propietari busca digitalitzar el seu negoci per tal de poder gestionar amb major agilitat i eficacia una guarderia canina.

Es tracta aleshores d'una empresa que ofereix serveis. En aquestes empreses la digitalització i la centralització de informació dels clients és una de les necessitats. El projecte de Gestor de Guarderia Canina respon a algunes d'aquestes necessitats mitjançant la gestió de les fitxes dels gossos, les reserves i el calendari d'estades.

L'estructura és simple amb un propietari que exerceix de cap i amb dos o tres empleats que gestionen el serveis als clients i gossos.


Com a client vull reservar un lloc a la guarderia canina
    - Funcionalitats:
        - Fer una reserva telefònica
        - Fer una reserva vía web
        - Cancel·lar una reserva
        - Afegir cures especials gos (medicaments, al·lergies)

Com a propietari vull gestionar la guarderia
    - Funcionalitats:
        - Consultar quins treballadors estan actius en eixe moment.
        - Consultar les entrades e ixides dels gossos
        - Gestionar els torns dels treballadors

Com a treballador vull registrar un gos.
    - Funcionalitats:
        - Crear fitxa
        - Introduïr les dades del gos a la fitxa


Com a treballador vull consultar les fitxes dels gossos
    - Funcionalitats
        - Mostrar llista de gossos
        - Buscar gos per nom
        - Buscar gos per data
        - Accedir a la fitxa
        - Consultar ocupació y disposició de la guarderia
        - Consultar cures especials (medicaments, al·lergies...)

Com a treballador vull crear reserves per als clients
    - Funcionalitats:
        - Seleccionar una data
        - Emplenar una reserva
        - Reservar una data
        - Consultar registres d'entrada i exides

Com a treballador vull consultar el calendari
    - Funcionalitats:
        - Mostrar reserves en el calendari
        - Seleccionar una reserva del calendari mostra dades de aquesta.
